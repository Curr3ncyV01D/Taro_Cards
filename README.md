**Асинхронный Telegram-бот для проведения Таро-раскладов с использованием GPT-4.**

Проект разработан как **коммерческое решение** (`исходный код был передан заказчику`). Бот имитирует личность таролога, анализирует запрос пользователя, проводит валидацию и выдает интерпретацию расклада из 3-х карт.

## ✨ Ключевые особенности
### 🧠 ИИ и Бизнес-логика
* **Персонализированные расклады:** Интеграция с OpenAI API (GPT-4/3.5) через системные промпты для глубокой интерпретации карт в контексте вопроса пользователя.

* **Умная валидация (Anti-Spam/Flood):** Система фильтрации входящих запросов. Бот отсеивает бессмысленный текст, спам и неэтичные вопросы до отправки запроса в API (экономия токенов).

* **Smart Caching:** Реализовано хэширование запросов. Повторные одинаковые вопросы не тратят бюджет API, а отдают готовый ответ из кэша.

* **Fail-safe Mechanism:** Если API недоступен, бот автоматически переключается на локальный алгоритм генерации предсказаний (Fallback), чтобы пользователь не остался без ответа.

### 🏗 Архитектура и Инфраструктура
* **Clean Architecture:** Четкое разделение слоев: ***Handlers*** (работа с Telegram), ***Services*** (бизнес-логика и AI), ***Database*** (хранение данных).

* **Полная асинхронность:** Бот написан на *Aiogram 3* с использованием асинхронного ORM (*SQLAlchemy + aiosqlite*).

* **Реферальная система:** Виральная механика роста. Пользователи получают дополнительные расклады за приглашение друзей (учет рефералов в БД).

* **Docker-Ready:** Проект полностью контейнеризирован. Поддерживается развертывание через docker-compose с persistent storage для базы данных.

## 🛠 Технический стек
**Язык:** Python 3.10

**Фреймворк:** Aiogram 3.x

**База данных:** SQLite (с возможностью легкой миграции на PostgreSQL) + SQLAlchemy

**AI:** OpenAI API

**Деплой:** Docker, Docker Compose

## 🚀 Установка и запуск
### Вариант 1: Через Docker (Рекомендуется)
Это самый быстрый способ развернуть проект.

**1. Клонируйте репозиторий:**



```Bash
git clone https://github.com/your-username/tarot-ai-bot.git
cd tarot-ai-bot
```
**2. Создайте файл конфигурации:**
Переименуйте `.env.example` в `.env` и укажите свои ключи:

~~~ Env
BOT_TOKEN=ваш_токен_телеграм
OPENAI_API_KEY=ваш_ключ_openai
~~~
**3. Запустите контейнер:**
```Bash
docker-compose up -d --build
```
### Вариант 2: Локальный запуск
**1. Установите зависимости:**


```Bash
pip install -r requirements.txt
```

**2. Настройте .env (см. выше).**

**3. Запустите бота:**
    
Запуск производится как модуль из корня проекта:
`python -m bot.main`

📂 Структура проекта
```Bash
.
├── bot/
│   ├── database/       # Модели SQLAlchemy и функции запросов
│   ├── handlers/       # Обработчики сообщений Telegram
│   ├── services/       # Бизнес-логика (AI генератор, валидаторы)
│   ├── config.py       # Конфигурация и переменные окружения
│   └── main.py         # Точка входа (Entry point)
├── Dockerfile          # Инструкция для сборки образа
├── docker-compose.yml  # Оркестрация контейнеров
├── requirements.txt    # Зависимости
└── .env.example        # Шаблон переменных окружения
```
